Exemple serveur

Le paiement reste asynchrone. Initiez avec curl, stockez le paymentId, puis attendez le webhook marchand.

curl -X POST http://localhost:8060/api/v1/payments/initiate \
  -H "Content-Type: application/json" \
  -H "X-API-Public-Key: {{ firstKey() }}" \
  -H "X-API-Secret-Key: sk_{{ currentEnvironment }}_YOUR_SECRET" \
  -H "Idempotency-Key: order-1001" \
  -d '{
    "amount": 5000,
    "country": "SN",
    "operator": "WAVE",
    "customer": {
      "phone": "221776006060",
      "firstname": "Awa",
      "lastname": "Diop",
      "email": "awa@example.com"
    },
    "returnUrl": "https://merchant.example/success",
    "cancelUrl": "https://merchant.example/cancel"
  }'
