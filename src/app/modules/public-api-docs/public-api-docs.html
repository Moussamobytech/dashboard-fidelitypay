Pay-in API

Encaisser un paiement mobile money

Créez une clé API dans le dashboard, initiez le paiement depuis votre serveur, puis attendez le webhook marchand. Le paiement n'est pas synchrone.

1. Authentification

Chaque appel marchand utilise ces headers. Ne mettez jamais la secret key dans le navigateur.

X-API-Public-Key: pk_live_xxx
X-API-Secret-Key: sk_live_xxx
Idempotency-Key: order-1001

2. Statuts utiles

  • PENDING: paiement créé, attente opérateur/client.
  • REQUIRES_ACTION: envoyez l'OTP via l'endpoint OTP.
  • SUCCESS: paiement confirmé.
  • FAILED/CANCELLED: paiement terminé sans succès.
  • PENDING_RECONCILIATION: résultat fournisseur incertain, FidelityPay réconcilie.

Webhooks marchands

Configurez votre endpoint dans le dashboard. FidelityPay envoie les événements payment.success, payment.failed, payment.cancelled et payment.requires_action.
